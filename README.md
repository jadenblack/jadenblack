Hey, I'm Jaden. This is my personal corner of GitHub: side projects and experiments, mostly agentic and AI tooling. Bots that run real workflows, the workspace they run on, and the glue in between. Things start here, get battle-tested, and the good ones graduate to [riolabs-ai](https://github.com/riolabs-ai).

### Focus

- **Agentic AI tooling**: Hermes bots, agent harnesses, MCP integrations
- **Workspace as code**: GitHub, Obsidian and Vercel as one durable setup
- **Small, sharp side projects** that scratch a real itch

### Highlights

- **[automaker-lite](https://github.com/jadenblack/automaker-lite)**: a lightweight AI-powered dev studio for managing projects and git worktrees.
- **[openclaw-vscode](https://github.com/jadenblack/openclaw-vscode)**: a VS Code / Antigravity extension for OpenClaw to manage builds and deploy agents.
- **[pwp-engine](https://github.com/jadenblack/pwp-engine)**: a WordPress enhancement platform with submodules for forms, security, MCP servers and n8n.
- **[agency-os](https://github.com/jadenblack/agency-os)**: a business operating system on Next.js + Directus.
- **[ghp-vscode-setup](https://github.com/jadenblack/ghp-vscode-setup)**: a Codex-managed VS Code setup, MVP.
